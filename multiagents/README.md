# Mahm Agent App

Claude-powered AI nutritionist with 4 tools: `search_recipes`, `get_nutrition`, `find_stores`, `generate_meal_plan`.

## Run locally

```bash
cp .env.example .env.local
# Add your ANTHROPIC_API_KEY to .env.local

npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
